# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-16

### Added
- Initial release of TaskManager
- Task management with create, edit, delete functionality
- Time tracking with start/pause timer for each task
- Task categories (work, personal, health, meeting, other)
- Weekly calendar view with task visualization
- Dark/Light theme toggle
- System tray integration with context menu
- Global shortcuts (Ctrl+Shift+T to show, Ctrl+Shift+Q to quit)
- Custom frameless window with title bar controls
- Task details modal
- Persistent data storage in JSON format
- Active tasks display panel

### Tech Stack
- Electron 38
- React 19
- TypeScript 5.9
- Mantine UI 8
- Vite 7
- electron-vite 4
